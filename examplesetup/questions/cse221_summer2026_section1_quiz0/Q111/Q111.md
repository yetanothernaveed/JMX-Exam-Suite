# Question

You are given an undirected, unweighted graph with `N` cities and `M` roads. The cities are numbered from `1` to `N`. The graph is connected: there is a path between every pair of cities. There are no self-loops and no multiple edges between the same pair of cities.

Perform a Breadth-First Search (BFS) starting from city `1` and print the order in which the cities are visited. Different neighbour orders can produce different traversals, so a graph may have multiple valid BFS orders. **You may print any valid BFS order.**

This is a complete-program problem. Input is provided in a file named `input.txt` in the current directory. **Read from `input.txt`; do not read from standard input.** Write your answer to standard output.

## Input

Read from `input.txt`. The first line contains a single integer `T` — the number of test cases.

For each test case:

- The first line contains two integers `N` and `M`.
- The next `M` lines each contain two integers `u_i` and `v_i`, describing a road between city `u_i` and city `v_i`.

## Output

For each test case, print a single line containing `N` space-separated integers: a valid BFS traversal order starting from city `1`.

## Constraints

- `1 <= T <= 10`
- `1 <= N <= 2 * 10^5`
- `0 <= M <= 3 * 10^5`
- The graph for each test case is connected, with no self-loops and no multiple edges. For `N = 1`, `M = 0`.
- The sum of `N` over all test cases is at most `10^6`, and the sum of `M` is at most `1.5 * 10^6`.

## Language notes

- **Java**: your submission is compiled as `Q111.java`, so your program must declare `public class Q111` with a `public static void main(String[] args)` method. Read `input.txt` with `BufferedReader` and `StringTokenizer`, and write with `PrintWriter`; see `Q111.java` for the expected style.
- **Python** and **C++**: submit a normal complete program that reads `input.txt` and writes to standard output.

## Example

Contents of `input.txt`:

```text
3
3 2
1 2
2 3
4 3
1 2
1 3
1 4
2 1
1 2
```

One valid output is:

```text
1 2 3
1 2 3 4
1 2
```

For the second test case, `1 3 2 4`, `1 4 3 2`, and many other orders are also valid because the leaves of the star may be visited in any order.
