# Question
Given two arrays, A and B, write a function according to the signature given below that returns a new array containing the difference of the corresponding elements of A and B (that is, A[i] - B[i]). Assume that both arrays have the same length N.

## Constraints
1 <= A[i] <= 100
1 <= B[i] <= 100
N <= 10e6

## Function Signatures
Java: int[] subtractTwoArrays(int[] A, int[] B)
Python: def subtract_two_arrays(A: List[int], B: List[int]) -> List[int]
C++: std::vector<int> subtractTwoArrays(const std::vector<int>& A, const std::vector<int>& B)
